⚙️ Platform Connections & Setup Guides

Connect social media accounts for automated publishing
📖 How to Connect Facebook Page:
  1. Open Meta Graph API Explorer ↗
  2. Select your Facebook App, choose your Page under User or Page, and grant pages_manage_posts, pages_show_list.
  3. Copy the generated Token and paste Page ID & Token below.
📖 How to Connect YouTube Shorts:
  1. Open Google Cloud Console ↗ and enable YouTube Data API v3.
  2. Create OAuth 2.0 Client ID (Web/Desktop).
  3. In OAuth Playground, authorize https://www.googleapis.com/auth/youtube.upload and copy Refresh Token.
  4. Paste Client ID, Secret, and Refresh Token below.
📖 How to Connect TikTok API:
  1. Open TikTok for Developers ↗ and create an App.
  2. Enable Content Posting API (Video direct publish v2).
  3. Paste Client Key, Client Secret, and User Access Token below.
